# UrbanKart Sales Analysis

## Project Overview

This project focuses on cleaning and analyzing UrbanKart's sales
dataset using MySQL and Excel.

## Tools Used

- MySQL
- SQL
- Microsoft Excel
- GitHub

## Data Cleaning

The dataset was cleaned by:

- Removing duplicate records
- Handling missing values
- Trimming unwanted spaces
- Standardizing date formats
- Validating quantity values
- Validating unit prices
- Validating total revenue
- Checking malformed records
- Creating a final analysis-ready dataset

## Key Findings

- Top region: South
- Total revenue: ₹39,364,228
- April → May growth: 8.4%
- May → June growth: 6.5%
- Weakest revenue channel: Marketplace
- Marketplace revenue share: 29.1%

## Project Files

- `data/` - Cleaned dataset
- `sql/` - SQL queries used for cleaning and analysis
